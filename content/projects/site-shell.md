# Portfolio Site Shell

This page describes the terminal website itself.

| Part | Choice |
|---|---|
| Interface | plaintext terminal |
| Content | Markdown files |
| Tables | ASCII output |
| Links | terminal commands or external URLs |

Example terminal block:

```text
open Projects
open /Projects/site-shell
map
```

The important rule is simple: keep the site readable as a console, even when the source text uses Markdown.
