Terms of use for Kal Résumé Editor

Kal Résumé Editor supports a private editing collaboration. Select a document you’re authorized to share with the editor. Include information in comments only if you’re comfortable sharing it with the document’s collaborators and having the editor process it as described in the privacy policy.

Kal offers suggestions. Review them for accuracy and use the wording you want. You can ask the operator to stop the editor or revoke the Google access you granted in your Google Account settings.

For help with the editor, use the support contact on the Google authorization screen.
