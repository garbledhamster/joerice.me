Privacy policy for Kal Résumé Editor

Kal Résumé Editor is operated by Joe Rice. It uses Google sign-in to verify the operator’s account. Google Picker grants the app access to the selected document. The editor checks the document’s revision and comments and may add a reply or editorial comment.

To prepare a reply, the editor sends relevant comment text and any selected passage to OpenAI through its API. When it reviews a document change, it may send a bounded excerpt of the document. The editor requests that OpenAI skip response storage through the API. Replies and editorial comments are visible to the document’s collaborators.

CLAI+ stores authorization credentials in protected storage on the operator’s Mac. The editor keeps a local record of document and comment identifiers, revisions, checks, delivery status, and any generated review of a document change. The record helps it track what it has already handled. The editor uses Google data for the collaboration described here.

The operator can stop the editor in CLAI+ and revoke its Google access from Google Account settings. For questions or requests about local records, use the support contact on the Google authorization screen.

The app’s use and transfer of Google API data follows the Google API Services User Data Policy, including its Limited Use requirements.
