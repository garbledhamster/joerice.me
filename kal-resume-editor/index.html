Kal Résumé Editor

Kal is an AI editing assistant for a private Google Doc. When a collaborator leaves a new comment asking for feedback, Kal can reply in the thread or leave a comment with suggested wording for the selected passage. It can also prepare a local review when the document changes. The writer decides which changes to use.

The operator chooses the file through Google Picker. The editor uses that file for the collaboration and checks for new comments while the operator has the schedule enabled.
